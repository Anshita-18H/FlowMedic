# Issue 5 — Limit large issue descriptions in previews

**Suggested state:** Open  
**Suggested labels:** `data-safety`, `usability`

## Body

Some issues may contain long descriptions. The importer and dashboard should use a predictable size limit for any stored or displayed description.

Acceptance criteria:
- Keep the original issue URL for full context.
- Bound the imported body length.
- Never put secrets or personal data into the sample demo issue.
